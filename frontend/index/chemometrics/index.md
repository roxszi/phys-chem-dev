# 化学计量学助手

> [!warning] 业务简介：
> 
> 化学计量学是化学门类中研究“数据”相关问题的学科。化学计量学助手即以化学数据为着眼点，满足化学数据收集、处理与分析等需求的各类小工具。

[[toc]]

## 1.  数据批量处理小工具

> 各类数据批量处理小工具，如我校物性分析仪器的原始数据处理小助手等，主要用于填补仪器原配软件的功能不足。

### 1.1  Andor拉曼光谱数据处理助手

[**功能链接**](andor-raman/)

可批量将大量Andor拉曼光谱仪的`.sif`数据文件，一键即可转为一个Excel表格文件。

## 2.  机器学习小工具

> 常用的物理化学数据处理软件（如Origin等）不包含的一些数据处理功能，如S-G插值平滑等。主要用于填补机器学习软件的功能不足。
